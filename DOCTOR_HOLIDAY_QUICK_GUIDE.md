# Doctor Holiday Management - Quick Start Guide

## 🚀 Quick Access

**Admin Dashboard → Doctors → Select Doctor → Manage Availability → Holidays & Time Off section**

## 📝 How to Add Holidays

### Full-Day Holiday (Doctor unavailable all day)

1. Click **"📅 Add Holidays"** button
2. Navigate to the month using Prev/Next buttons
3. **Click on date(s)** to select (multiple selections allowed)
4. Select **"Full Day"** radio button
5. (Optional) Enter reason: "Vacation", "Conference", etc.
6. Click **"Add Holiday(s)"** button

✅ **Result:** Doctor completely unavailable on selected dates

---

### Half-Day Holiday (Doctor unavailable for specific hours)

1. Click **"📅 Add Holidays"** button
2. Navigate to the month and **select date(s)**
3. Select **"Half Day"** radio button
4. Set **Start Time** (e.g., 08:00)
5. Set **End Time** (e.g., 12:00)
6. (Optional) Enter reason
7. Click **"Add Holiday(s)"** button

✅ **Result:** Doctor unavailable during specified time range only

---

## 🎯 Common Scenarios

### Scenario 1: Week-Long Vacation
```
Dates: Select 7 consecutive days
Type: Full Day
Reason: "Annual Vacation"
Result: 7 full-day holidays
```

### Scenario 2: Afternoon Off
```
Dates: Select single day
Type: Half Day
Start: 13:00
End: 18:00
Reason: "Personal Time"
Result: Morning appointments available, afternoon blocked
```

### Scenario 3: Conference (Multiple Days)
```
Dates: Select 3 days (e.g., Mon-Wed)
Type: Full Day
Reason: "Medical Conference"
Result: 3 full-day holidays
```

## 📊 Visual Guide

### Calendar Colors
- 🟣 **Purple** = Currently selected
- 🔴 **Red with border** = Already a holiday
- ⚪ **White** = Available to select
- ⚫ **Gray** = Outside schedule range (disabled)

### Holiday Badges
- 🔴 **Red badge** = Full Day
- 🟡 **Yellow badge** = Half Day (shows time range)

## ✏️ Managing Holidays

### View Holidays
- All holidays appear in a list above the calendar
- Shows: Date, Type, Time (if half-day), Reason

### Remove Holiday
- Click the **✕** button next to any holiday in the list

### Edit Holiday
- Remove existing holiday
- Add new holiday with updated details

## ⚠️ Important Rules

✅ **Date Range**: Holidays must be within the availability schedule dates  
✅ **Half-Day Times**: Start time must be before end time  
✅ **Multi-Select**: Select multiple dates for bulk holiday creation  
✅ **Time Format**: Use 24-hour format (HH:MM)

## 🔍 Quick Tips

1. **Bulk Creation**: Select all dates at once (e.g., all Fridays in a month)
2. **Check Existing**: Red-bordered dates already have holidays
3. **Clear Selection**: Click selected dates again to deselect
4. **Close Calendar**: Click "✕ Close Calendar" when done

## 🎓 Example Workflow

```
1. Open Doctor Availability Modal
   ↓
2. Scroll to "Holidays & Time Off" section
   ↓
3. Click "📅 Add Holidays"
   ↓
4. Select date(s) from calendar
   ↓
5. Choose Full Day or Half Day
   ↓
6. (If half-day) Set start/end times
   ↓
7. Add optional reason
   ↓
8. Click "Add Holiday(s)"
   ↓
9. See holidays appear in list above
   ↓
10. Click "Update Availability" to save
```

## 🆘 Need Help?

- **Gray dates not clickable?** → They're outside your schedule range
- **Can't add holiday?** → Check if date is already a holiday
- **Half-day not saving?** → Ensure both start and end times are set
- **Changes not appearing?** → Click "Update Availability" button at bottom

---

**Pro Tip:** You can select holidays first, then update the weekly schedule, states, and all other settings before clicking the final "Update Availability" button!
